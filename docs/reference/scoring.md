# P-values and scores

Exact P-values and score thresholds, and the scores and probabilities of individual matches. Scores use the motif's PWM on the same integer grid as scanning, with each entry multiplied by 1000 and truncated, so that a score and its P-value always agree with what [`scan_sequences()`][universalmotif.scan_sequences] reports.
